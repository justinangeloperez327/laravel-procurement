# Laravel Procurement

Philippine government procurement management system aligned with Republic Act No. 12009 (New Government Procurement Act) and its applicable implementing rules and GPPB issuances.

## Architecture

- Laravel 13 modular monolith
- PHP 8.4+
- React 19 + TypeScript
- Inertia.js
- Tailwind CSS 4
- PostgreSQL
- Redis + Horizon
- S3-compatible object storage
- Pest

## Initial Domain Scope

1. Organization and identity
2. Suppliers
3. Fiscal years
4. Market scoping
5. PPMP
6. APP
7. Procurement projects
8. BAC and bidding
9. Evaluation and post-qualification
10. Awards and contracts
11. Delivery and inspection
12. Supplier performance
13. Approvals, documents, notifications, reports, and audit
